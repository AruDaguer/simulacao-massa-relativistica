### 🌌 Sobre o Projeto

Este repositório contém a simulação desenvolvida para o trabalho de física e matemática, focada na **Teoria da Relatividade Restrita** de Albert Einstein. O objetivo é provar visualmente e matematicamente, através do cálculo de limites, o motivo pelo qual nenhum corpo com massa pode alcançar ou ultrapassar a barreira de velocidade **$c$** (velocidade da luz).
